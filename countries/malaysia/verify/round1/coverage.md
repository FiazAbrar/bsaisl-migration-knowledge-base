# Coverage check: malaysia.src.md against IMI's visa and pass list

Verifier label: coverage. Checked 6 Nov 2026. I did not edit `malaysia.src.md`.

**How the official list was built.** The list comes from IMI's own Main Services menu (Perkhidmatan Utama > Visa, Pas, Permit Masuk, Pas Sempadan, Pembantu Rumah Asing, APEC card, Syarat Kemasukan, MM2H, Program Istimewa), saved in `raw/imi-en-types-of-visas.txt` (English menu) and `raw/imi-ikad-collection.txt` (Malay menu). It also includes the eVISA options on MyVISA (`raw/myvisa-home-fc.md`, `raw/myvisa-faq.md`), IMI's online-service tiles (`raw/imi-home.md`: PVIP, eVDR, PLS@XPATS, eSP) and the ESD expatriate passes. Most pages were already saved. I fetched five more with curl: `imi-pvip-faq` (the PVIP FAQ PDF, metadata date 4 Sep 2025), `imi-macs`, `imi-border-pass` (its body was empty; only the menu came back), `imi-abtc-eligible` and `imi-seaman-entry`. I registered these, plus `imi-program-istimewa`, `imi-section66-exemption`, `imi-notice-evoa-closure`, `imi-documents-by-category` and `imi-employment-pass`, which were saved but not registered. Every pass type is now a part-C ledger row: C0001 to C0048 in `ledger-parts/C.csv`. Every IMI page has no date, so these rows are `possibly-outdated`. The MyVISA rows are `verified`.

DE Rantau and MTEP are run by MDEC (Malaysia Digital Economy Corporation), not IMI, so their rows (E0084, E0081) come from MDEC pages. They are included because the brief names them.
