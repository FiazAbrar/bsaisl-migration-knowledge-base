# How do I check if the visa is genuine?

------------------------------------------------------------------------

![Immigration & Checkpoints Authority logo](/_next/image?url=https%3A%2F%2Flogos.ask.gov.sg%2Ficalogo.png&w=3840&q=75)

Updated by ICA 3y ago

------------------------------------------------------------------------

68 found this helpful

You may check your visa using the ['Enquire Application Status'](https://eservices.ica.gov.sg/ipsave/index.xhtml) via the [ICA e-Service](https://eservices.ica.gov.sg/esvclandingpage/save). You will need to enter the visa reference number and the applicant's travel document number to retrieve the e-Visa.
