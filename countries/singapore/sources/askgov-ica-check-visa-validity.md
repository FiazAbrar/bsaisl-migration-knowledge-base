# How do I check my visa validity?

------------------------------------------------------------------------

![Immigration & Checkpoints Authority logo](/_next/image?url=https%3A%2F%2Flogos.ask.gov.sg%2Ficalogo.png&w=3840&q=75)

Updated by ICA 2y ago

------------------------------------------------------------------------

35 found this helpful

The visa validity is indicated on the e-Visa. You can retrieve your e-Visa using the [Enquire Application Status](https://eservices.ica.gov.sg/ipsave/index.xhtml) function and key in your Visa Reference Number and Travel Document Number.

If you do not have a visa application reference number, you may [contact us via the enquiry form](https://go.gov.sg/ica-visa-enquiry) and indicate the applicant's name and passport number for the retrieval of visa application reference number.
