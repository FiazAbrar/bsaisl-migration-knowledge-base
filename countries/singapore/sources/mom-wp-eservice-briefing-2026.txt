        Enhancement 1: Apply for Temporary Permit (TP)

    With progressive enhancements to the Work Permit application process, the time taken to get the
    Work Permit issued has reduced.
    Today, for non-Malaysians, the in-principle approval (IPA) letters allow workers to start work from their
    second day of arrival in Singapore. For new Work Permit applications from 29 Nov 2026, workers can
    only start work after their Work Permit is issued, or if they have a Temporary Permit (TP).
    You should get the Work Permit issued as soon as possible. If you are unable to complete issuance
    steps and need your worker to start work urgently, you may use the new Apply for TP function on
    myMOM Portal to request for a TP.

                             Workers are not allowed to start work without an issued Work Permit or TP.
