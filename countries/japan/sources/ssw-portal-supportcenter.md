# Immigration Information Center

Getting Support for Using the Specified Skilled\
Worker Program

Foreign nationals who want to work under a Specified Skilled Worker status of residence can telephone the call center if there is anything about the procedures they don’t understand. It can assist with filling out paperwork and other procedures.
