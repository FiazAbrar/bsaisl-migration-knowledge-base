Information on Tests Related to the Specified Skilled Worker System

Proficiency Tests

In order to work under a Specified Skilled Worker (i) status of residence, you need to pass a Japanese language test and a skills proficiency test. (You do not need to pass these tests if you have satisfactorily completed Technical Intern Training (ii). However, to work in a different field, you need to pass a skills proficiency test in the field in which you wish to work.) Taking these tests costs money.

In order to work under a Specified Skilled Worker (ii) status of residence, you need to pass a Specified Skilled Worker (ii) skills proficiency test. Work experience might be required in order to take tests. For more details, check the test information.

Important Notes

  • The test schedules on this page are based on information from the websites of the government agencies and organizations offering the tests.
  • The information on the websites of the government agencies and organizations offering the tests might be more recent than the information shown on this page. Please be sure to check the website of the government agency or organization offering the test you are interested in.
  • You can access the websites of the government agencies and organizations offering these tests via the “Test Information” page on the website of the Ministry of Justice. (Japanese only) (http://www.moj.go.jp/isa/policies/ssw/nyuukokukanri01_00135.html)
  • If you wish to take a test, you should check the website of the government agency or organization offering the test and carry out the required procedure.
  • We recommend the use of JFT-Basic as a test for measuring your Japanese language proficiency.
