# eVisa Kingdom of Cambodia (Official Government Website): Visa Type Information
Source: https://www.evisa.gov.kh/information/visa_type/4 (Firecrawl scrape, 11 Nov 2026)

Last Updated: Jan 01, 2025

| Visa T (Tourist Visa) |
| --- |
| Entry Type | Single entry only |
| Fee | USD 30 |
| Validity | 3 months(starting from the date of issue) |
| Length of Stay | 1 month |
| Processing time | 3 business days |
| Requirement | Passport validity of more than six months balance at the time of entry, a recent passport-size photo in digital format (JPEG or PNG format), a valid credit card (Visa/MasterCard). |
| Visa Exemption | Laos, Malaysia, Philippines, Singapore, Vietnam, Thailand, Indonesia, Brunei Darussalam, Myanmar |

| Visa E (Business Visa) |
| --- |
| Entry Type | Single entry only |
| Fee | USD 35 |
| Validity | 3 months(starting from the date of issue) |
| Length of Stay | 1 month |
| Processing time | 3 business days |
| Requirement | - Passport validity of more than six months balance at the time of entry, a recent passport-size photo in digital format (JPEG or PNG format), a valid credit card (Visa/MasterCard). |

| Visa A (Diplomatic Visa) |
| --- |
| Description | This visa is issued to accredited diplomats and their family members holding Diplomatic Passports and/or EU Laissez-Passers, and officials of the United Nations holding Red Laissez-Passers. |
| Length of Stay | 3 months |
| Entry Type | Multiple entry |
| Validity | 3 months (starting from the date of issue) |
| Processing time | 15 days |

| Visa B (Official Visa) |
| --- |
| Description | This visa is issued to non-immigrant foreigners holding Official/Service Passports who are undertaking official government missions or missions with an international organization that has a valid memorandum of understanding with the Ministry of Foreign Affairs and International Cooperation, including officials of the United Nations holding Blue Laissez-Passers. |

| Visa C (Courtesy Visa) |
| --- |
| Description | This visa is issued, as a courtesy, to non-immigrant foreigners and their family members, as determined by the Ministry of Foreign Affairs and International Cooperation. |
