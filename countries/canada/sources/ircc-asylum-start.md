# Start an asylum claim

Claiming asylum isn’t a shortcut to staying in Canada longer.

Asylum claims are intended for people who need Canada’s protection.

If Canada decides you don’t need protection, you may need to leave the country.

Before you start a claim, [check what makes an asylum claim eligible](/en/immigration-refugees-citizenship/services/refugees/asylum/eligibility.html).
