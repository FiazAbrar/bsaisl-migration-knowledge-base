NOTA SULLA SEGNALAZIONE STATISTICA DELLE RIMESSE DEI LAVORATORI |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  | 
 |  |  |  |  |  |  |  |  |  |  |  |  |  |  |  | 
 |  |  |  |  |  |  |  |  | 
I dati sulle "rimesse dei lavoratori" verso l'estero comprendono esclusivamente i trasferimenti internazionali di denaro tra due persone fisiche, effettuati tramite un istituto di pagamento o altro intermediario autorizzato, senza transitare su conti di pagamento intestati all’ordinante o al beneficiario (regolamento in denaro contante o strumenti ad esso assimilati).
L'aggregato qui pubblicato corrisponde alla serie mensile BOP_BP6.M.N.IT.W1.S1W.S1.T.D.D752W._Z._Z._Z.EUR._T._X.N pubblicata in BDS (tavola TBP 60080).
In conformità con la vigente regolamentazione, la Banca d'Italia rileva tramite la matrice dei conti le informazioni da banche residenti e istituti di pagamento italiani che prestano il servizio di rimessa di denaro. |  |  |  |  |  |  |  |  | 
Da gennaio 2005 a dicembre 2015 la periodicità della rilevazione è stata mensile e la frequenza della pubblicazione trimestrale. Dal 2016 sia la rilevazione sia la pubblicazione hanno frequenza trimestrale.
L’informazione segnalata riguarda gli importi delle rimesse e il numero di operazioni, disaggregate per provincia italiana di residenza del mittente e per stato estero di residenza del beneficiario.
Il sistema di raccolta dati è operativo dal 2006 (dal 2010 per i regolamenti in contante tramite il canale bancario). Il primo anno di riferimento dei dati pubblicati è il 2005. I dati sul 2005 sono stati raccolti nella fase preparatoria del sistema di rilevazione; il dettaglio per provincia del 2005 è stato stimato in base alle informazioni raccolte nel 2006. Dal 2006 tutti i valori pubblicati corrispondono a quanto segnalato dagli operatori, senza soglia di rilevazione. A partire dal secondo trimestre del 2018, l’obbligo di segnalazione è stato esteso a nuove categorie di intermediari specializzati, che solo in parte aderivano alla segnalazione dei flussi su base volontaria. Ciò ha determinato un salto di serie, in particolare nei flussi bilaterali relativi ad alcuni paesi asiatici.
