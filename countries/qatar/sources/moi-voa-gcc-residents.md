#### Free on-Arrival Tourist Visa valid for 30 days (extendable) for 39 countries 

The nationals of following countries are granted free on-arrival visa for a period of (30) days extendable for a similar period.

 

|  |  |  |  |  |  |
|---:|---:|---:|----|----|:--:|
| Andorra | Australia | Azerbaijan | Bolivia | Britain | Brunei Darussalam |
| Canada | Chile | China | Colombia | Costa Rica | Cuba |
| Ecuador | Georgia | Guyana | Monaco | Hong Kong | Indonesia |
| Ireland | Japan | Kazakhstan | Lebanon | Maldives | Mexico |
| Moldova | New Zealand | North Macedonia | Panama | Paraguay | Peru |
| Rwanda | Bosnia and Herzog | San Marino | Singapore | Suriname | United States |
| Uruguay | Vatican | Venezuela |   |   |   |

 

**Conditions and Requirements:**

1-  Passport valid for at least three months.

2- Availability of confirmed return ticket.

3- Confirmed hotel reservation at any hotel in Qatar during the visit period, or a clear address of the stay.

4-  Health insurance from an accredited [insurance company](https://www.moph.gov.qa/arabic/derpartments/policyaffairs/hfid/hirs/insurancecompanies/Pages/default.aspx)
