# Residence Permit Application Tracking

Ministry of Interior

Service Type

E-Service

Last updated

12 Jan 2021

## Service Description

This service allows for easily tracking the residence permit application approval status.

## Steps

- Enter visa number and ID Number of Sponsor/Representative/Authorized Signatory.
- Enter verification code from the picture or audio.
- Click on “Submit”.

## Fees

No fees are required for this service.

## Additional Information

For more information and details, please contact MOI by dialing 2367111.
