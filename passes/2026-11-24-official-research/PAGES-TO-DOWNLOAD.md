# Pages to download by hand

These official pages blocked automated reading or loaded empty. Open each in a browser and save it (Print, then Save as PDF), name it as suggested, and put it in the doc's folder under `manual/`; the next research step will log what it proves. Most important first.

## Settle a question in a doc

1. **Bangladesh Bank circular on the Tk 1,000 crore skills and language loan scheme run through PKB** (SME and Special Programmes Department, 2026): https://www.bb.org.bd/en/index.php/mediaroom/circular. Settles the scheme's terms and whether it replaced PKB's 11% language loan. Folder: `global/services/manual/`, name `bb-skills-loan-circular-2026.pdf`.
2. **US State Department, immigrant-visa pause notice** (live page): https://travel.state.gov/en/newsroom/visas/2026/immigrant-visa-processing-updates-for-nationalities-at-high-risk-of-public-benefits-usage.html. The doc now relies on a lawyers' association copy. Folder: `countries/united-states/manual/`, name `state-iv-pause-2026.pdf`.
3. **US State Department, countries subject to visa bonds**: https://travel.state.gov/content/travel/en/News/visas-news/countries-subject-to-visa-bonds.html. Folder: `countries/united-states/manual/`, name `state-visa-bond-countries.pdf`.
4. **BMET clearance statistics by country (OEP report)** for the USA, Canada, UK, Greece, Lebanon and India, 2022 to 2026: https://www.oep.gov.bd/reports/country-clearance (pick the country and year). Folder: each country's `manual/`, name `bmet-clearance-<country>.pdf`.
5. **Portugal, Law 61/2025** (family reunification): diariodarepublica.pt (search "Lei n.º 61/2025"). The doc relies on a law firm's alert. Folder: `global/other-destinations/manual/`, name `pt-lei-61-2025.pdf`.
6. **India visa application centre, visa types and documents**: https://www.ivacbd.com/kind-of-visas-documents. Folder: `countries/india/manual/`, name `ivac-visa-types.pdf`.
7. **Lebanon Ministry of Labour** (clearance-certificate fee, domestic workers): https://www.labor.gov.lb/. Folder: `countries/lebanon/manual/`.
