# Datasets

Collections gathered for the knowledge base, kept with the scripts that built them so they can be reused, extended or rebuilt. One folder per dataset, each with a README giving its source, period, how it was collected, files and fields, how it was used, and its limits.

- [prothom-alo-migration](prothom-alo-migration/): Prothom Alo stories on migration, 1 Jan 2024 to 22 Nov 2026 (27,907 raw, 1,787 flagged as migration-related), with per-article facts, scam cases and agency flags extracted from them.

To add a dataset: give it a folder; keep the raw data compressed and unchanged in `raw/`; put each derived file in its own folder with the brief that produced it; keep the collection scripts in `scripts/`.
