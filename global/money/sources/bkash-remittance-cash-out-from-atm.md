**ATM Cash Out Request**

A security code is required to Cash Out from an ATM using any bKash Account. Customers can get the security code by following the steps below -

- Dial \*247# to access bKash Mobile Menu or login to the bKash App
- Choose ‘Cash Out’
- Choose ‘From ATM’
- Enter your bKash PIN Number
- A security Code (OTP) will be sent to the registered mobile number via SMS. The code will remain active for 5 (five) minutes and can be used only once.

***Cash Out from BRAC Bank ATM***

To withdraw cash from any BRAC Bank ATM that has bKash Cash Out option, a security code is required. Customers can get the security code by following the steps below -

- Dial \*247# to access bKash Mobile Menu or login to the bKash App
- Choose ‘Cash Out’
- Choose ‘From ATM’
- Enter your bKash PIN Number
- A security Code (OTP) will be sent to the registered mobile number via SMS. The code will remain active for 5 (five) minutes and can be used only once.

Now, follow the steps below to Cash Out at the ATM booth:-

- Click on the 'bKash Cash Out' button at the bottom left corner of the ATM screen
- Choose your preferred language
- Enter the bKash Account Number
- Enter the amount for Cash Out
- Enter the security code (OTP) received via SMS
- Verify and confirm the information provided
- Receive money and receipts
- Get a confirmation SMS from bKash
